# Support

Agctor is a community project. The maintainers do not offer a paid SLA.

## How to get help

1. Read the [README](README.md) and [CONTRIBUTING](CONTRIBUTING.md) guides.
2. Search [existing issues](https://github.com/rahamohebbi/Agctor/issues).
3. Open a new issue with the bug or feature template.

Security reports belong in [SECURITY.md](SECURITY.md), not in public issues.

## What to include in a bug report

- Agctor commit SHA and .NET SDK version (`dotnet --version`)
- OS
- Exact command or API call
- Logs and a minimal reproduction when possible
